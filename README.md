### 🦇 About me

I build small tools that fix real annoyances: bots that answer customers while I sleep, alerts that ping me the second tickets open, and a wallet viewer that never touches your keys. Most of it runs **free and always on** with Cloudflare Workers.

#### [Batwallet](https://github.com/MalluGitWayne/batwallet)

A minimalist, **read-only** Android crypto wallet viewer. Paste, share or scan any address and it figures out the network, then shows balances, history and safety checks. It never asks for private keys and can't move funds.

- 🌐 **~30 networks**: Tron, BSC, Ethereum, Solana, Bitcoin, TON and more
- 🛡️ **Safety check** before you send: scam lists, freeze lists, lookalike-address warnings
- 📋 **Smart paste**: drop in a whole chat message and it finds the address
- 🌙 Black OLED theme, English / Русский / हिन्दी
